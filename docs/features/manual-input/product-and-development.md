# 手动输入：统一入口

状态：已实现，待用户实机验收。日期：2026-09-07。

## 操作流程

设置 → 通用 → 录音设置下方的「手动输入」，配置一个全局快捷键。首次迁移优先沿用旧版中没有冲突的手动输入快捷键，否则使用 Control + Option + Space；若已有其他功能占用，不覆盖其绑定。

按快捷键打开输入窗，输入或粘贴文字后，点击顶部模式或按它的快捷键提交。窗口打开期间，模式快捷键用于处理文字，不启动录音；长按类型的模式键也在按下时提交，松开不会再次提交。再次按入口快捷键或 Esc 关闭输入；输入法组字时 Esc 先退出候选。

顶部模式使用当前配置的顺序，展示第一组快捷键，其他已有绑定也可提交。快速模式和 Ask Anything 不在这个文字处理入口中。超过可用宽度的模式从右侧展开。模式及其提示词在打开时冻结，关闭后恢复普通语音快捷键。

## 外观与鼠标

沿用用户选中的第二张设计：独立胶囊模式条 + 下方文字区。默认一行，无提交按钮、波形和底部说明。换行后向上增高，删除后收回；高度达到上限后内部滚动。底边固定，明亮和暗色均沿用现有悬浮窗主题。

模式悬停时高亮，移出后恢复；只有点击或模式快捷键才处理文字。空白输入不提交，并保留编辑焦点。Enter 换行，中英文输入、粘贴、复制和撤销走原生文本编辑器。

## 处理与兼容

打开输入窗前冻结输出目标，并采集可选模式所需的选中文字、剪贴板、智能感知上下文。手动文字替代 ASR 文本传入既有模式处理和输出链路，包括 `{text}` 模板、输出格式及历史记录。手动入口不申请麦克风、不调用 ASR、不做语音词汇替换，也不计语音识别时长。

未捕获到原应用时走剪贴板兜底。原应用退出或输出失败时沿用安全输出策略。旧 `manualInputHotkey` 字段仅用于读取与迁移，不再注册为独立入口，也不出现在模式详情设置中。

新的统一快捷键保存在 `tf_manualInputHotkeyV2`。设置复用模式快捷键的胶囊按钮及录制弹窗，支持编辑、重录和删除。与模式键重合时，提示占用者，确认后仅移除其冲突绑定；修饰键前缀冲突沿用模式的提醒。与改口键重合时阻止保存；清除后的空绑定会被保留，不会重启后恢复默认。

## 验收边界

已添加快捷键状态机回归用例，编译应用与测试目标；按本地 UI 迭代约定不运行测试套件、不操控界面或启动录音。最终明暗外观、输入法、自动增高、鼠标提交和回填由用户在正式安装包中体验验收。

## 聚焦与输入法修正（2026-09-07）

编辑器在挂入窗口后补做首次聚焦；窗口显示与延迟布局均可完成这个请求，成功后不再抢占用户主动移动的焦点。关闭时清除待处理的聚焦请求。

占位文字由原生文本编辑器绘制。仅在文字为空且没有输入法组字时显示；拼音组字、确认、取消和删除都会刷新占位文字及输入区高度，不依赖确认汉字后才产生的文本变化通知。

## 阴影边界修正（2026-09-07）

手动输入窗单独为阴影预留四周 32 点透明空间，窗口初始尺寸、输入自动增高和 SwiftUI 外边距使用同一数值。同步补偿窗口底部坐标，保持可见输入框的宽度、屏幕位置及阴影样式；不修改录音悬浮窗的共享布局参数。实机阴影效果仍由用户体验验收。
